### <h3> Título de Nível 3 (Pequeno)

Este é um parágrafo de teste comum para você validar o tamanho da fonte, o espaçamento entre linhas (_line-height_) e a cor do texto principal em ambos os modos (claro e escuro).

---

## Estilização de Texto Básica

Você pode testar elementos de ênfase no meio do texto:

- Este texto está em **negrito** para destacar termos importantes.
- Este texto está em _itálico_ para citações ou estrangeirismos.
- É possível combinar ambos para criar algo **_negrito e itálico_**.
- Também temos o texto ~~riscado~~ para itens obsoletos.

## Elementos de Código (Muito importante para temas!)

Para destacar variáveis ou comandos rápidos no meio do texto, usamos o `inline code` (como `Navigator.push()` ou `Color(0xFF212121)`). É crucial testar se o fundo dele tem um contraste bom.

Abaixo está um bloco de código completo (_Code Block_) simulando uma sintaxe de C# para validar o bloco inteiro:

```csharp
using System;

public class Program
{
    public static void Main()
    {
        // Testando o visual de comentários e estruturas
        string mensagem = "Olá, Mundo!";
        Console.WriteLine(mensagem);
    }
}
```
